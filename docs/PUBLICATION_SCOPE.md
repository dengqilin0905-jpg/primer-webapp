# Publication scope

Publish application source, generic CLIs, package metadata, dependency locks, software documentation, empty configuration schemas, generated generic workbooks and artificial examples/tests only. PUBLICATION_FILES.txt lists the exact software snapshot. No original experimental map, real sequencing input, project registration, database, physical colony record, personal path or private acceptance report is part of the distribution.

Private resources are loaded externally with unchanged scientific checks. Laboratory working trees, original files and historical outputs are preserved. Private integration tests retain the original scientific assertions; public CI uses artificial fixtures without laboratory filesystem access.

Validation: public synthetic regression, the complete 180-case external private regression without skips, eleven unchanged private case results, wheel installation into a fresh environment, installed CLI health, account/login/all-page/custom-backbone smoke and installed canonical export/verification. Native SnapGene alignment output is not implemented.

The release is assembled as new commits on public origin/main. The unpublished private development commits are not ancestors and must not be pushed. Snapshot and new-object scanning do not erase files that were already in the public base's older history. This release removes inherited experimental fixtures from the software tree while preserving them privately. A separate repository-history cleanup is necessary to remove any such already-public historical objects; no original branch or remote history is rewritten by this preparation.

The prepared workflow runs CI only and never deploys. Before a later merge, disable the remote repository's older automatic deploy workflow and require PR review/checks. Software synchronization and private laboratory deployment remain separate approvals.
