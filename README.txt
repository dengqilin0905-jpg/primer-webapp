Primer WebApp (Windows Portable)

How to run:
1) Unzip the package
2) Double-click: run.bat
3) Your browser will open automatically.

Notes:
- Data is stored at: %APPDATA%\PrimerWebApp\app.db
- If you update the app, keep that file to preserve your history.
- If Windows SmartScreen warns, click "More info" -> "Run anyway" (common for unsigned internal tools).
